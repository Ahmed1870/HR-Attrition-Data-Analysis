##  Executive Summary

This project delivers a **full end-to-end Data Analytics workflow** designed to answer a critical HR question: **Why are employees leaving, and which specific workforce segments require targeted intervention?**

Rather than jumping straight into visualization, this project approaches workforce analytics methodically—covering data validation, exploratory query writing in SQL, statistical EDA in Python, and culminating in an interactive Power BI dashboard with actionable HR recommendations.
